# 我是大老板（I'm the Boss!）

Sid Sackson 经典谈判桌游《I'm the Boss!》的网页单机版：1 名人类 + 2–5 名电脑玩家围桌谈判分成。

- 规则按官方版图 / 景气牌 / 98 张影响牌实现，谈判被结构化为有限步的回合制，人类与电脑同桌且对局必定收敛。
- 四个对局版本：**经典 · 15 笔**（官方原味）、**完整 · 16 笔**（打满 16 格，牌堆加入稀有牌）、**扩张 · 22 笔**（24 格版图，混入地标 / 抢手 / 黑市 / 猎头格，股价升到 $6M）、**马拉松 · 30 笔**（32 格、4 座地标、股价 $7M）。
- 扩展规则：**夺回权**（最后一位常驻投资者被夺走时，1 张招募牌就能抢回）、稀有牌（利好 / 利空 / 独家协议）、特殊格（地标收租、抢手加价、黑市无反应窗口、猎头两张招募）——详见 [docs/rules.md §10](./docs/rules.md)。
- **桌规**（开局可开关，经典默认关、其余默认开）：**换牌**（持有某家族投资者时，该家族成员卡 ↔ 同家族旅行牌，每回合一次）、**买牌**（回合开始付 1 / 3 / 6 份股价多抽 1 / 2 / 3 张）、**兑换**（两张不同种类的牌 + 一份股价 → 2 张招募牌）、**病假牌**（指定一人本回合不能主动出牌，只能被动打阻止牌）。另有对所有版本生效的**缺代表速流局**：桌上凑不齐代表且全员一轮无实质进展即流局；代表齐全时连续两轮无进展流局，重复原价也计入停滞。
- 对手从八位牌桌常客里随机抽出——沈砚青、陆峥、顾曼宁、何烬、周慕言、苏澜、程亦舟、白珩——各有出身、谈判风格与软肋。
- 电脑玩家可接入任意 OpenAI 兼容接口：模型拿到的是角色卡与一张看得清的牌桌，自己判断、自己说话，还会给下一回合的自己记笔记；未配置或调用失败时由内置启发式策略按同一人物接管。两者都只能从引擎枚举的合法动作中选择，游戏不会因为 AI 出错而卡住。
- 无后端、无数据库。对局自动存档在浏览器 `localStorage`（含终局，"继续上一局"回到存档那一刻）；开局可填种子，同一种子的发牌、骰子与启发式决策完全可复现，每局记录动作日志，"开局参数 + 日志"可完整重放。

## 快速开始

```bash
npm install
npm run dev          # 开发服务器（http://localhost:3000）
npm run build        # 类型检查 + 产物构建（dist/）
```

## 怎么玩

1. 开始页选择人数（3–6 人，含你）、对局版本（15 / 16 / 22 / 30 笔）、是否开桌规、名字，可选种子；有存档时可续局。
2. 顶部引导条告诉你当前阶段与该做什么；底部行动区只显示此刻合法的操作；点手牌可查看并打出这张牌。
3. 开单后先是**叫价轮**：从 Boss 左手边起每人喊价 / 出牌 / 跳过，Boss 听完所有人的价再提第一版方案。
4. **报价即承诺**：你公开报的出借价（每个代表）在本笔交易内有效——Boss 付到这个价你就自动同意；付不到才会问你同意 / 拒绝（可反报价）。报低了会被照价成交，报高了会被竞争者压价顶替。报价按家族分开记：手里有几个相关代表，行动区就有几个价格框，一句话报完各家的价——给唯一代表的那家报高价、给有竞争者的那家报低价；留空的家族价不动。拒绝方案时同样可以对每个被选用的代表分别反报价。
5. 作为 Boss：用方案编辑器挑代表、定分成（编辑器会标出谁会自动同意、谁还需应答），全员同意后宣布成交；其他玩家有一次最后出牌的机会。
6. 作为非 Boss：喊话报价、打家族卡入局或压价抢单、用旅行 / 招募 / 老板牌搅局或夺权，或者索要封口费。行动区会提示你的筹码（唯一代表 / 有竞争者 / 缺口）。
7. 右侧标签页：谈判桌（席位竞价与当前方案）、日志（默认折叠跳过 / 放行，可勾选显示）、交易历史（每笔分成与累计收入，含地标租金）。
8. 扩张 / 马拉松版里留意格子上的徽标：🏛 地标成交后每笔收租、🔥 抢手股价 +$1M、🕶 黑市出牌无人能阻止、🎯 猎头两张招募牌就能挖人。谁的最后一位投资者被挖走，座位上会亮出"夺回权"——1 张招募牌抢回来。
9. 开了桌规：回合开始时行动区多一条"桌规"操作条（按价买 1 / 2 / 3 张、兑换招募牌——点选两张不同种类的牌确认）；持有某家族投资者时，点该家族的成员卡 / 旅行牌会多出"换牌"按钮；病假牌点开选目标。座位上的 🤒 表示这个人本回合出不了牌。
10. 电脑玩家的重要动作会在版图下沿弹出提示（与你有关的更醒目、停留更久，点击即关）；每笔交易结束有结算卡（谁拿了多少、你的收益、流局原因）。顶栏可调电脑速度（快 / 中 / 慢）、⏩ 快进跳过当前停顿、开关合成音效；⚙️ 设置里可调动画速度（关 / 快 / 标准 / 慢，即时生效，与电脑速度互不影响）；LLM 徽标显示模型是否正常（降级 / 暂停时给出原因）。座位上的图标是这位对手对你的态度，悬停可看原因。
11. 终局卡给出排名、现金曲线、精彩时刻与各项统计；点"逐步复盘"可按动作 / 按交易步进回看整局（含所有人的手牌）。
12. 手机 / 平板可直接玩：侧栏变成抽屉（手柄上有未读数），行动区与手牌固定在底部，长按卡牌或带说明的元素查看详情；支持键盘操作与读屏，尊重系统的"减少动态效果"设置。
13. 点 📖 查看规则速查（按当前版本与桌规开关显示扩展规则），点 ⚙️ 配置 LLM。

## LLM 设置（游戏内 ⚙️）

| 配置项 | 说明 |
| --- | --- |
| Base URL / API Key / 模型名 | 任意 OpenAI 兼容 `chat/completions` 接口（DeepSeek、OpenAI、Ollama、vLLM…） |
| 温度 | 决策任务建议 0–0.6（默认 0.5） |
| 请求超时（秒） | 默认 30；thinking / reasoning 模型建议调大。超时后本次决策自动降级为启发式（人物口吻不变）；连续失败会暂停调用 LLM，冷却后自动探测恢复，顶栏徽标显示状态 |
| LLM 决策范围 | 关键决策（默认：需要合作的可行开单、报价、提案、应答、出影响牌、封口费问模型，其余由启发式按同一人物处理）/ 全部 |
| 桌风 | 友好 / 商战 / 冷血，与开始页同一设置，下一局生效 |
| 自定义请求体 | JSON 对象，顶层字段合并进请求。例：DeepSeek 关思考 `{"thinking":{"type":"disabled"}}`、Qwen `{"enable_thinking":false}`、OpenAI `{"reasoning_effort":"low"}` |
| AI 行动节奏 | 只影响电脑行动前的停顿观感 |

面板底部可查看最近 20 条调用日志（用途 / 耗时 / 请求与响应预览）。

## 目录

```
src/
  engine/       纯函数引擎：types / config / rules / validator / gameEngine（不含任何文案）
  text/         文案层：narrate（事件 → 文字）、labels（动作 / 卡牌 / 方案 → 文字），UI 与 LLM 提示词共用
  ai/           电脑玩家：policy（接口）/ heuristic（启发式）/ llmPolicy + prompts（按局面拼提示词）+ personas / llmClient
  prompts/      LLM 提示词的全部静态文案：角色卡 / 桌风 / 框架与回复格式 / 规则摘要（见目录内 README.md；npm run prompts:preview 预览）
  game/         对局运行时（框架无关）：session（GameSession：持有状态、驱动电脑玩家、节奏停顿、动作日志）/ replay（开局参数 + 动作日志完整重放）/ createSession（依赖注入）/ autosave（节流存档）
  hooks/        useGameSession：把 GameSession 接进 React；browserEnv：装配浏览器环境（LLM + 启发式回退、localStorage、停顿）
  components/   React 界面（ActionDock、CardHand、OfferEditor、NegotiationPanel、TableBoard、GameOverCard …）；ViewerContext（视角玩家）、useModalDismiss / useDialogLayer（弹层关闭与焦点）、CueProvider + CueStage（演出层）、review/（终局统计与逐步复盘）
  ui/           界面纯逻辑：提示 / 事件流 / 结算摘要 / 演出调度 / 卡面 / 统计与精彩时刻 / 复盘导航 / 布局档位（均有单测）
  audio/        Web Audio 合成音效（无音频文件）与开关 / 音量状态
  sim/          仿真工具：整局运行 + 不变量检查 + 重放校验（CLI 与测试共用）
  utils/        storage（分层存档：head + 日志分块）/ saveMigrations（两级版本迁移）/ seed（种子输入解析）
tests/          vitest：静态数据 / 规则场景 / 合法动作性质 / 运行时 / 重放与存档 / LLM 协议 / 整局仿真 / 版本与扩展规则 / 桌规；ui/ 为 jsdom 组件测试
scripts/        simulate.ts：命令行批量仿真与单局追踪（四个版本轮换或指定，桌规可开关，打印桌规用量）
docs/           规则、架构、AI、开发指南、重构对照
```

## 验证

```bash
npm run typecheck          # 严格模式 TypeScript（含 tests/）
npm test                   # vitest：规则 / 运行时 / 重放与存档 / 组件测试，含 3~6 人整局仿真、四个版本与桌规
npm run simulate -- 400    # 400 局回归：启发式 / 随机各半、四个版本轮换，逐步断言不变量（SIM_REPLAY=1 另校验每局可重放）
npm run check              # 以上三项串行
```
