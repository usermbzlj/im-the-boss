# 《I'm the Boss!》规则手册（本项目实现版）

本文是项目实现所依据的完整规则。版图、景气牌、牌堆构成来自官方规则
（Sid Sackson 原作 *Kohle, Kie$ & Knete*；Face2Face Games 英文版 *I'm the Boss!*），
第 9 节说明数字版为了让人类与 AI 同桌而对"自由谈判"所做的结构化约定，
第 10 节是本项目自行设计的**扩展内容**：四个对局版本（15 / 16 / 22 / 30 笔）、夺回权、特殊格与稀有牌。
第 1–8 节描述的是"经典 · 15 笔"版本；其他版本在第 10 节列出的差异之外与经典版完全相同。

**代码即规范**：所有静态数据以 `src/engine/config.ts` 为唯一来源，本文表格与其保持一致；
若两者冲突，以代码为准并修正本文。

## 1. 概览

| 项目 | 内容 |
| --- | --- |
| 人数 | 3–6 人（本项目：1 名人类 + 2–5 名 AI） |
| 目标 | 游戏结束时现金最多者获胜，并列则并列获胜 |
| 核心 | 围绕一笔笔交易谈判分成；用影响牌临时代替投资者、打飞对手代表、夺取投资者或 Boss 身份、取消对手的牌 |
| 组件 | 16 格版图、6 张投资者牌、98 张影响牌、15 张景气牌（交易价值牌）、1 枚六面骰、1 个金钱标记（经典版；其他版本见第 10 节） |

### 1.1 核心概念

- **Boss**：当前交易的主导者。发起交易的人成为 Boss，可被老板牌夺走。Boss 决定用谁的代表、给谁多少钱，并宣布成交或放弃。
- **投资者**：6 位，代号 A–F。投资者牌是公开的长期控制权，谁持有谁就能代表该家族参与交易。
- **家族成员牌**：手牌中的临时代理人，打出后只在本笔交易中代表对应家族。
- **代表**：投资者牌或家族成员牌统称"代表"。交易能否成立只看"有效代表"是否凑齐。
- **交易格**：版图上 16 格，各自规定需要哪些家族、几份分红。
- **景气牌**：15 张，编号 1–15，决定当前"每份分红"的价值；成交后盖到成交格上，该格永久关闭。

### 1.2 家族

字母代号与颜色沿用原版顺序；名称为本项目自拟。

| 代号 | 游戏内名称 | 颜色 |
| :-: | --- | :-: |
| A | 星桥资本 | 红 |
| B | 赤岩集团 | 橙 |
| C | 银湾基金 | 黄 |
| D | 蓝鲸实业 | 蓝 |
| E | 绿洲商会 | 绿 |
| F | 黑松控股 | 紫 |

每个家族对应 1 张投资者牌、4 张家族成员牌、3 张定向旅行牌。

## 2. 开局

1. **投资者牌**：洗混后按人数分配。

   | 人数 | 分配 |
   | :-: | --- |
   | 3 | 每人 2 张 |
   | 4 | 每人 1 张，余 2 张面朝上放入公共区 |
   | 5 | 每人 1 张，余 1 张放入公共区 |
   | 6 | 每人 1 张 |

   公共区的投资者不属于任何人，只能通过招募三连取得。
2. **影响牌**：洗混 98 张，每人发 5 张，其余为抽牌堆；弃牌堆初始为空。
3. **景气牌**：按编号 1→15 叠放，1 号在最上方（当前生效）。
4. **起始资金**：0。
5. **起始玩家**：持有字母序最靠前投资者（A 优先）的玩家；4/5 人局中若该投资者在公共区则顺延到下一个有主的家族。
6. **金钱标记**：起始玩家**右手边**的玩家把标记放在任意一格。

---

## 3. 回合

轮到你时，先二选一：

1. **发起当前格交易**：立即成为 Boss，进入谈判（第 5 节）。
2. **掷骰移动**：金钱标记顺时针移动骰数格，**已关闭的格子跳过、不计步数**。移动后再二选一：
   - 发起新位置的交易；
   - **抽 3 张影响牌**，结束回合。

抽牌后若手牌超过 **12 张**，必须立刻处理到不超过 12 张：弃牌；或先打出一组招募三连（进入反应窗口），再重新检查。投资者牌不计入手牌。

交易结束（成交或流局）后，由**最终 Boss 左手边**的玩家开始下一回合。

## 4. 交易需求与金额

### 4.1 需求组

每格的需求由一个或多个**需求组**构成，每组列出若干家族并要求其中 `need` 个不同家族有有效代表：

- `need = 家族数`：**全部必需**（如 "A、B"）。
- `need < 家族数`：**N 选 M**（如 "C、D、E 选 2"）。

同一格各组的家族互不重叠。有些格没有必需组只有可选池（2、9、10、14 格），10 格有两个可选池。

### 4.2 金额

```
交易总金额 = 当前景气牌的每份价值 × 该格分红份数
```

分红份数 = 该格所需投资者总数 + 1。例如第 7 格需要 5 位投资者、6 份分红，在 $3M/份 时总额 $18M。

## 5. 谈判

### 5.1 有效代表

| 来源 | 性质 | 归属 |
| --- | --- | --- |
| 投资者牌 | 长期控制权，可被招募夺走 | 持有者 |
| 家族成员牌 | 本笔交易的临时代理，打出后不可收回 | 打出者 |

- Boss 自己的代表默认参与、免费。
- 别人的代表是否参与取决于谈判：Boss 通常要付分成，对方也可以拒绝。
- 同一家族可能同时有多个代表（投资者牌 + 一张或多张家族成员牌）。Boss 只需**选其一**满足该家族需求；落选者分文不得。
- 被旅行牌命中的代表在本笔交易中失效（第 6.2 节）。

### 5.2 成交方案

Boss 提出的方案必须写明：选用哪些代表；给每位玩家多少钱；Boss 自己保留多少。
分成总额不能超过交易总金额；Boss 可以把钱分给没有提供代表的人（例如买其"不搅局"）。

### 5.3 成交条件

1. 每个需求组都被有效代表满足；
2. 方案中所有被选用代表未失效、且其持有者同意；
3. 分成总额 ≤ 交易总金额；
4. 宣布成交后，其他玩家都放弃了最后一次出牌机会（第 9 节）。

### 5.4 成交结算（按顺序）

1. 银行把交易总金额付给 Boss；
2. Boss 按方案付给各玩家；
3. 被选用的家族成员牌进入弃牌堆，未选用且未被打飞的回到原主手牌；
4. 当前景气牌盖到该格，该格永久关闭；景气牌堆翻到下一张；
5. 盖在投资者上的旅行牌进入弃牌堆，投资者恢复；
6. 金钱标记自动移到顺时针方向**下一个未关闭格**；
7. 若为第 10 笔及以后，最终 Boss 掷终局骰（第 7 节）；
8. 未结束则由最终 Boss 左手边的玩家开始新回合。

### 5.5 流局

Boss 可随时放弃；必需家族无法凑齐、谈判僵局（第 9 节）也会流局。流局时：
不产生现金；该格不关闭；景气牌不消耗；金钱标记不动；未被打飞的家族成员牌回手；
其他打出的影响牌进入弃牌堆；Boss 的回合立即结束（不能再掷骰或抽牌），由其左手边玩家开始下一回合。

## 6. 影响牌（98 张）

| 类型 | 数量 | 作用 | 可被阻止 |
| --- | :-: | --- | :-: |
| 家族成员 | 24（每家族 4） | 成为对应家族的临时代表 | 否 |
| 旅行 | 21（18 定向 + 3 万能） | 让一个代表在本笔交易失效 | 是 |
| 招募 | 33（须 3 张一组） | 永久夺取一张投资者牌 | 是 |
| 老板 | 10 | 夺取 Boss 身份 | 是 |
| 阻止 | 10 | 取消刚打出的旅行 / 招募三连 / 老板牌 | 否 |

通用规则：影响牌只能在交易进行中（谈判阶段与成交倒计时）打出，Boss 也可以打；阻止牌只能在目标牌刚打出的反应窗口使用；交易正式关闭后不能再打牌影响该交易。

### 6.1 家族成员牌

- 打出后放在桌面成为该家族代表，无论投资者牌在谁手里（或在公共区）。
- 不能被招募或阻止，可以被旅行牌命中。
- 结算：被选用成交 → 弃牌堆；未选用 → 回手；被旅行牌命中 → 已弃置，不回手。

### 6.2 旅行牌

- 定向旅行牌只能指定同家族的代表；万能旅行牌任意。
- 目标必须是**当前桌上的代表**（有主的投资者牌，或已打出的家族成员牌）。
- 命中投资者牌：该投资者本笔交易失效，旅行牌盖在其上，交易结束后恢复。
- 命中家族成员牌：与旅行牌一起进入弃牌堆，不再回手。
- 旅行牌命中的是具体代表而非整个家族：同家族的另一代表仍可使用。
- 若命中的代表在当前方案中，方案作废，Boss 须重新提案。

### 6.3 招募牌（三连）

- 3 张一起打出，指定一张**投资者牌**（不能指定家族成员牌）。
- **公共区优先**：4/5 人局中只要公共区还有投资者，就必须先招募公共区的；公共区空了才能夺别人的。
- 成功后所有权立即转移；若该投资者已被旅行牌打飞，失效状态持续到本笔交易结束。
- 若该投资者在当前方案中，方案作废。
- 也可在抽牌后手牌超限时打出，然后重新检查手牌上限。
- **夺回权**（本项目规则，所有版本适用）：谁的**最后一位**常驻投资者被招募夺走，谁就获得对该家族的夺回权——只需 **1 张**招募牌即可把那张投资者牌抢回来（等效于三连；无论它此刻在谁手里，也不受"公共区优先"限制）。重新拥有任何投资者（夺回或招到别家）后夺回权失效；夺回时若让对方也失去了最后一位投资者，对方同样获得夺回权。见第 10.2 节。

### 6.4 老板牌

- 只能在有交易进行中时打出，打出者立即成为新 Boss，原方案作废。
- 桌面状态全部继承：已打出的家族成员牌、已被打飞的代表、已易主的投资者都保持。
- 同一笔交易可多次易主，以最后一位成功掌控者为最终 Boss（决定下一回合从谁开始）。

### 6.5 阻止牌

- 只能在旅行 / 招募三连 / 老板牌刚打出时使用，取消其效果；被取消的牌照常进入弃牌堆。
- 任何人都可以打，包括替别人挡（例如取消打向盟友的旅行牌）。
- 不能取消另一张阻止牌，不能取消家族成员牌。

### 6.6 交互表

| 打出的牌 | 可被阻止牌取消 | 可被旅行牌影响 | 可被招募影响 |
| --- | :-: | :-: | :-: |
| 家族成员牌 | 否 | 是 | 否 |
| 旅行牌 | 是 | 否 | 否 |
| 招募三连 | 是 | 否 | 否 |
| 老板牌 | 是 | 否 | 否 |
| 阻止牌 | 否 | 否 | 否 |
| 投资者牌 | — | 是 | 是 |

---

## 7. 终局

- 前 9 笔成交后游戏必定继续。
- **第 10 笔成交起**，每次成交后由最终 Boss 掷骰：掷出的点数在该笔景气牌的终局骰面中，游戏立即结束。
- 第 15 笔成交后游戏自动结束。
- 结束时现金最多者胜，并列则并列获胜。
- 其他版本：最后 6 张景气牌带终局骰面（1 / 1–2 / … / 1–6），即"第 `笔数 − 5` 笔起可能终局、最后一笔必定结束"，见第 10.1 节。

## 8. 常见判例

| 问题 | 判定 |
| --- | --- |
| Boss 必须自己提供代表吗？ | 不必。凑齐有效代表并谈妥分成即可成交，Boss 因"组织交易"获利。 |
| 能付钱给没有代表的人吗？ | 可以，常用于买其不搅局。 |
| 能在成交前先收钱吗？ | 不能。所有支付在成交时结算，口头承诺不具强制力。 |
| Boss 成交后能反悔吗？ | 不能。宣布成交且无人干扰即按方案付款。 |
| Boss 谈判中能改方案吗？ | 可以，正式成交前随时可加价、换代表或重提。 |
| 家族成员牌能收回吗？ | 不能，打出后留在桌上直到交易结束或被打飞。 |
| 投资者被打飞，同家族成员牌还能用吗？ | 能。反之亦然。 |
| 招募能夺被打飞的投资者吗？ | 能，但失效状态维持到本笔交易结束。 |
| 一笔交易能多次换 Boss 吗？ | 能，最后一位成功者为最终 Boss。 |
| 流局后 Boss 还能行动吗？ | 不能，回合立即结束；金钱标记不动。 |

## 9. 数字版实现约定

桌面版的谈判是自由发言、随时出牌的；本项目把它结构化为**有限步的回合制**，以便人类与 AI 同桌并保证对局一定能收敛。以下约定不改变规则本身，数值来自 `src/engine/config.ts`。

| 约定 | 内容 | 对应 |
| --- | --- | --- |
| 叫价轮 | Boss 开单后，从 **Boss 左手边**起顺时针轮流行动，Boss 在第一轮**末位**；每次可：喊话报价 / 打影响牌 / 跳过，Boss 轮到时还可提案、宣布成交或放弃。这样 Boss 提第一版方案时已经听过所有人的价。Boss 打出自己的家族卡后不换人，可以紧接着提案或成交 | 5 节 |
| 喊话次数 | 每人每笔交易最多 4 次公开喊话（可附报价） | 防止无限对话 |
| 报价语义 | 有本格所需家族代表者报价 = **每个代表**的出借价；无代表者报价 = 不搅局的封口费 | 5.2 |
| 按家族分开报价 | 报价**按家族分别记录**，一次喊话就能报完每个代表各自的价：同一玩家可以给唯一代表的家族报高价、给有竞争者的家族报低价（"赤岩 $4M、银湾 $2M"），互不覆盖；只报一部分家族则其余家族的价不动。行动区默认为每个代表一个价格框；只填一个"通用价"则本格自己所有相关代表同价。打家族卡附带的报价只针对那张卡的家族；拒绝方案时也可对方案用到的每个代表分别反报价 | 桌面上本就如此 |
| 报价即承诺 | 公开报出的价对本笔交易有效：Boss 的方案付到 `Σ 被选用的你的每个代表各自的报价`，你**自动视为同意**，不再询问；任一被选用代表没报过价，或付不到合计价，才询问你同意 / 拒绝。同意一个方案会把 `实付 ÷ 代表数` 记为所用家族的新承诺价；拒绝时的反报价（每个代表）也是新承诺价 | 5.3 条件 2 |
| 提案 → 应答 | Boss 提案（每任 Boss 最多 5 次，易主后清零）→ 未自动同意的代表持有者依次同意 / 拒绝（可附反报价）；任何人拒绝即方案作废回到谈判，由 Boss 行动 | 5.1 |
| 方案时效 | 方案中的代表被打飞或易主时自动作废，回合回到 Boss | 5.3 |
| 成交倒计时 | Boss 宣布成交（须方案全员同意，或只用自己的代表）→ 其他玩家依次获得最后一次出牌机会（旅行 / 招募 / 老板牌）；全员放行即结算；有牌生效则回到谈判。人类玩家手中没有可打的干扰牌时自动放行 | 5.3 条件 4 |
| 反应窗口 | 旅行 / 招募三连 / 老板牌打出后，按座位顺序询问其他所有玩家是否打阻止牌；无阻止牌者只能放行。询问所有人（而非只问持牌者）是为了不暴露谁持有阻止牌 | 6.5 |
| 僵局 | 全员连续跳过一整轮记为停滞；连续 2 轮停滞判流局 | 5.5 |
| 手牌上限 | 抽牌后超过 12 张进入弃牌阶段，可先打招募三连再弃牌 | 3 节 |
| 随机性 | 洗牌与掷骰使用带种子的确定性随机数；开局可指定种子完整复现对局 | 复盘 / 回归测试 |

"报价即承诺"是对桌面版口头承诺的数字化：桌面上你说了"$6M 就出人"，Boss 照价付了你却反悔，会被全桌记住；这里直接由引擎兜底。
它同时让谈判有了真实的博弈张力：报低了会被照价成交，报高了会被竞争者压价顶替；Boss 则可以选择"付到承诺价一次成交"或"压价试探一次、再照价付"。

### 9.1 完整回合范例

金钱标记在第 12 格（必需 C、D、E；A/B/F 选 1；5 份分红），当前第 12 张景气牌（$4M/份），总额 **$20M**，一份分红 $4M。

1. 玩家 1 发起交易成为 Boss。玩家 1 持有 C，玩家 4 持有 D、E。
2. **叫价轮**从玩家 2 起：玩家 2 打出家族成员 F 并报价 "$4M"。玩家 3 没有相关代表，跳过。玩家 4 有两张相关投资者，一句话分开报价："E 只有我有，$6M；D 便宜点，$3M。"（只算一次喊话）
   有效代表：C（玩家 1）、D、E（玩家 4）、F（玩家 2 家族卡）——需求满足。玩家 4 的承诺价合计 = $6M + $3M = $9M。
3. 轮到玩家 1（Boss）：提案 代表 C、D、E、F；分成 玩家 2 $4M、玩家 4 $9M；自留 $7M。
   两人的承诺价都付到了 → **自动视为同意**，方案立即可成交。（若玩家 1 只付玩家 4 $8M，则只询问玩家 4；玩家 4 可同意——D、E 的承诺价都变为 $4M——或反报价。）
4. 玩家 1 宣布成交，进入倒计时，从玩家 2 起依次询问。玩家 2 放行。轮到玩家 3：打出旅行牌指向 E 投资者 → 反应窗口依次询问玩家 4、1、2：玩家 4 打出阻止牌取消，两张牌进弃牌堆，E 仍有效。被取消的牌不打断倒计时，仍轮到玩家 3。
5. 玩家 3 再打出老板牌 → 反应窗口中玩家 2 打出阻止牌取消。玩家 1 仍为 Boss。玩家 3 无牌可打，放行；玩家 4 放行。
   （若第 4 步的旅行牌未被取消，则 E 失效、方案作废、倒计时中断，回到谈判由 Boss 重新提案。）
6. 结算：银行付玩家 1 $20M；玩家 1 付玩家 2 $4M、玩家 4 $9M，自留 $7M；玩家 2 的家族成员 F 弃置；景气牌 12 盖到第 12 格；金钱标记移到下一个未关闭格。
7. 这是第 12 笔成交：玩家 1 掷终局骰，掷出 1、2、3 则游戏结束；否则由玩家 1 左手边玩家开始下一回合。

## 10. 扩展内容：对局版本、夺回权、特殊格、稀有牌

以下内容为本项目设计，不在官方规则中。开局时选择版本；所有数值以 `src/engine/config.ts` 为准。

### 10.1 四个版本

| 版本 | 成交笔数 | 版图 | 股价 | 首次可能终局 | 牌堆 | 稀有牌 | 特殊格 |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| 经典 · 15 笔 | 15 | 16 格（官方） | $2M → $5M | 第 10 笔 | 98 | 否 | 否 |
| 完整 · 16 笔 | 16 | 16 格（官方） | $2M → $5M | 第 11 笔 | 105 | 是 | 否 |
| 扩张 · 22 笔 | 22 | 24 格（官方 16 + 新 8） | $2M → $6M | 第 17 笔 | 117 | 是 | 是 |
| 马拉松 · 30 笔 | 30 | 32 格（官方 16 + 新 16） | $2M → $7M | 第 25 笔 | 129 | 是 | 是 |

- **景气牌**由生成器按"股价从 $2M 均匀升到末张股价、最后 6 张带 1 / 1–2 / … / 1–6 终局骰面"生成；`makeDealTiles(15, 5)` 与官方 15 张完全一致。
- **完整 16 笔**把经典版图 16 格全部打满：第 16 笔成交（版图关闭）即结束。
- **版图**：新格与经典格交错排成一圈（新格均匀散布），按顺时针重新编号；新格同样满足"分红 = 投资者数 + 1"、同格家族不重叠。
- **牌堆**：稀有牌 7 张（利好 3、利空 2、独家协议 2）；每个补充包 12 张（家族成员 6——每家 1、招募 3、万能旅行 1、老板 1、阻止 1），扩张 1 包、马拉松 2 包。
- 夺回权（10.2）适用于所有版本，包括经典版。

### 10.2 夺回权

| 触发 | 效果 | 失效 |
| --- | --- | --- |
| 你的最后一位常驻投资者被招募夺走 | 你获得对**该家族**的夺回权：打出 **1 张**招募牌即可把这张投资者牌抢回（无论此刻在谁手里，不受"公共区优先"限制；同样进反应窗口、可被阻止；也可在手牌超限时打） | 你重新拥有任何投资者（夺回成功，或花 3 张招到别家）时消失 |

夺回若让对方也失去了最后一位投资者，对方同样获得夺回权——一张投资者牌可能被两人来回争夺，每次都要花一张招募牌。

### 10.3 特殊格（扩张 / 马拉松）

| 格 | 效果 |
| --- | --- |
| 🏛 地标 | 成交时的 Boss 成为该格**主人**；此后每一笔成交（任何格）结算时，银行额外付给每位地标主人 $1M 租金（本格自己这笔不付）。流局不付租。剩余笔数越多，地标越值钱 |
| 🔥 抢手 | 该格股价 **+$1M/份**（与利好 / 利空叠加） |
| 🕶 黑市 | 该格交易中打出的旅行 / 招募 / 老板 / 稀有牌**不经反应窗口直接生效**，阻止牌在这里无用 |
| 🎯 猎头 | 该格交易进行中招募只需 **2 张**（夺回权仍是 1 张）；手牌超限阶段不在交易中，仍是 3 张 |

### 10.4 稀有牌（完整 / 扩张 / 马拉松）

| 牌 | 数量 | 谁能打 | 效果 | 可被阻止 |
| --- | :-: | --- | --- | :-: |
| 📈 利好 | 3 | 只有 Boss（谈判阶段） | 本笔股价 **+$2M/份**；已有方案不作废、别人的分成不变，多出来的全归 Boss | 是 |
| 📉 利空 | 2 | 只有非 Boss（谈判阶段或成交倒计时） | 本笔股价 **−$1M/份**（下限 $1M/份）；已有方案不作废、别人的分成不变（付款按总额封顶），砍的是 Boss 的净得。打出者计入"干扰者" | 是 |
| 🔒 独家协议 | 2 | 只有 Boss（谈判阶段） | 锁定本笔交易：此后任何人都不能再打老板牌 / 旅行牌 / 利空牌（招募、家族成员卡、利好仍可）。易主不解锁 | 是 |

Boss 打出利好 / 独家协议、反应窗口结束后回合仍在 Boss，可紧接着提案或成交。股价变动只作用于当前这笔交易，成交后景气牌照常翻到下一张。
